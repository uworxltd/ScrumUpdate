### 🧭 **1. ScrumUpdate – System Context (ASCII)**

```
               +----------------------+
               |   Microsoft Teams    |
               |  (External System)   |
               +----------+-----------+
                          |
                          | HTTPS
                          v
                 +------------------+
                 |   Teams Bot      |
+---------+      |  (in ScrumUpdate)|      +----------+
| Member  | ---> |                  | <--- |Supervisor|
|         | <--- |   Web App        | ---> |          |
+---------+      |  (in ScrumUpdate)|      +----------+
                 +------------------+
                          |
                          | REST / API
                          v
                 +------------------+
                 |   Jira (External)|
                 +------------------+
```

🗝 **Summary:**
Members and Supervisors use either the **Web App** or **Teams Bot** (inside Microsoft Teams) to interact with **ScrumUpdate**, which integrates with **Jira**.

### 🏗️ **2. ScrumUpdate – Container View (ASCII)**

```
                  +-----------------------------+
                  |       ScrumUpdate SaaS      |
                  |-----------------------------|
                  |                             |
                  |   +---------+      +------+ |
User via Web ---> |   |  KBS    | ---> | KGS  | |
or Teams Bot ---> |   |         | ---> | KAS  | |
                  |   |         | ---> | KSS  | |
                  |   |         | ---> +------+ |
                  |   +----+----+               |
                  |        |                    |
                  |        v                    |
                  |   +-----------+             |
                  |   | PostgreSQL|             |
                  |   +-----------+             |
                  +-----------------------------+
```

🗝 **Flow summary:**

* **Web App → KBS (HTTP)**
* **Teams Bot → KGS (HTTP)**
* **KBS → KGS, KAS, KSS (HTTP)**
* **All → PostgreSQL (SQL)**

### 📘 **3. Definitions**

| Code                | Full Name                  | Tech                        | Description                                     |
| ------------------- | -------------------------- | --------------------------- | ----------------------------------------------- |
| **KBS**             | Khoji Business Server      | Java / Spring Boot          | Core business logic and entry point for web app |
| **KGS**             | Khoji Gen AI Server        | .NET / ASP.NET Minimal APIs | AI and natural language processing              |
| **KAS**             | Khoji Analytics Server     | Python / Flask              | Analytics and reporting computations            |
| **KSS**             | Khoji Sync Server          | Python                      | Syncs Jira data                                 |
| **PostgreSQL**      | Database                   | —                           | Each service has a separate schema              |
| **Microsoft Teams** | External System            | —                           | Platform for Teams Bot                          |
| **Jira**            | External System            | —                           | Project data source                             |
